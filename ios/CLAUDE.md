# Pre Post — iOS app

Pre Post is a personal, single-user iOS app for building Instagram carousel posts outside Instagram and publishing them through the Instagram API. This directory is the SwiftUI app. It creates and keeps multiple drafts, each with photos (added from the Photos library and reordered), a caption (typed or generated by Claude), a free-text location and a category. It publishes through the Worker at `prepost-api.aurlaw.dev` and then hands off to Instagram so the location can be added. Draft metadata lives locally (SwiftData, from A1). Images live in R2 and are referenced by URL. The app holds no secrets except the bearer token, which is stored in the Keychain.

The sibling `worker/` directory holds the API.

## Manual vs. automated split

Michael does these by hand. Claude Code must **not** do them:

- No git commands (commit, push, branch, etc.).
- No deploys, no `wrangler secret put`, no KV/R2 provisioning (Worker side).
- **No `project.pbxproj` edits.** If a change genuinely needs one (new target, capability, build setting, file outside a synchronized folder), stop and list the manual Xcode step instead.

Claude Code may create, edit and move files under the synchronized folders `PrePost/` and `PrePostTests/`. Xcode picks those changes up without a project-file change. Claude Code may also build and run tests with `xcodebuild`.

## Public-repo hygiene rules

- Never commit secrets or account identifiers (tokens, API keys, `.p8`, Apple Team ID, APNs Key ID, Instagram user ID, Cloudflare account ID).
- Never commit personal content: real photos, captions, Instagram handles, media IDs, permalinks, Page IDs — not in tests, fixtures, previews, sample data, or prompts.
- Tests and previews use generated placeholder images and lorem-style text.
- Credential-shaped test strings are built at runtime (split concatenation), never literals.
- New config values: non-secret → `wrangler.jsonc` `vars` / `Base.xcconfig`; secret or personal → `wrangler secret` / `Local.xcconfig` (gitignored) with a placeholder in the `.example` file.

## Configuration

- `Configs/Base.xcconfig` is committed and holds no personal values. It is attached to every build configuration and `#include?`s the gitignored `Configs/Local.xcconfig`, which supplies `DEVELOPMENT_TEAM` and optional local overrides. Do not modify the xcconfig files unless a brief says so.
- `PREPOST_API_BASE_URL` reaches the app through the `PrePostAPIBaseURL` key in `PrePost/Info.plist`, and is read and validated by `App/AppConfig.swift`. Don't hard-code the URL anywhere else.
- **Team ID guard:** with automatic signing, Xcode writes `DEVELOPMENT_TEAM` back into `project.pbxproj`. A git clean filter strips those lines on staging. It is declared in the repo root's `.gitattributes`, but each clone must configure it:
  ```sh
  git config filter.strip-team.clean "sed '/DEVELOPMENT_TEAM = /d'"
  git config filter.strip-team.smudge cat
  ```
  Check before committing: `git show :ios/PrePost.xcodeproj/project.pbxproj | grep -c DEVELOPMENT_TEAM` should print `0`.

## Layout

- `PrePost/App/`: app entry point and `AppConfig`.
- `PrePost/Views/`: SwiftUI views.
- `PrePost/Models/`: SwiftData models.
- `PrePost/Services/`: API client, Keychain, upload queue.
- `PrePost/Resources/`: asset catalog and app icon.
- `PrePost/Info.plist` stays at the root of `PrePost/`. The `INFOPLIST_FILE` build setting and the folder's membership exception both point to it.
- Don't use `.gitkeep` files to hold empty folders. The synchronized folder copies them into the app bundle, where they collide. Use a comment-only `.swift` placeholder instead.

## Conventions

- Swift 6 strict concurrency, SwiftUI, Swift Testing. iOS 26 minimum, iPhone only. No third-party packages unless a brief says so.
- The app target uses `MainActor` default isolation. Mark pure logic that tests call synchronously as `nonisolated`.
- Test parsing and validation functions directly, not through `Bundle.main`.
- Run the unit tests before declaring a task done. Use an iOS 27 simulator, because the test targets currently deploy to 27.0:
  ```sh
  xcodebuild test -project PrePost.xcodeproj -scheme PrePost \
    -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -only-testing:PrePostTests
  ```
